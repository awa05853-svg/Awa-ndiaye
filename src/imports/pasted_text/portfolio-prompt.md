## PROMPT — CRÉATION D’UN PORTFOLIO WEB PROFESSIONNEL

Tu es un **designer UI/UX senior, directeur artistique digital et développeur frontend expert** spécialisé dans la création de portfolios professionnels modernes.

### OBJECTIF

Crée un portfolio web **moderne, élégant, professionnel, chaleureux, féminin et responsive** pour présenter le profil de :

**Nom :** Awa Ndiaye
**Métier :** Assistante digitale
**Spécialités :** UX/UI Design, Design digital, Gestion de projet
**Localisation :** Sénégal
**Profil :** Assistante digitale en développement de compétences dans le numérique, avec un intérêt particulier pour l’UX/UI, la conception de solutions numériques, le design et l’innovation.

Le portfolio doit être conçu pour **convaincre des recruteurs, clients, entreprises, partenaires et collaborateurs potentiels**.

---

# 1. DIRECTION ARTISTIQUE

Créer une identité visuelle :

* moderne
* professionnelle
* élégante
* féminine mais **sans utiliser systématiquement du rose**
* chaleureuse
* minimaliste
* premium
* épurée
* facilement lisible
* avec beaucoup d’espace blanc
* avec une excellente hiérarchie visuelle
* avec des animations légères et élégantes

### Palette imposée

Utiliser principalement :

* **Blanc : #FFFFFF**
* **Vert : #009A44**
* **Rouge : #CE1126**
* **Bleu : #0085C7**

Le blanc doit rester la couleur dominante.

Le vert doit servir principalement pour les boutons, éléments importants et accents.

Le bleu peut être utilisé pour certains titres, liens ou éléments graphiques.

Le rouge doit être utilisé avec parcimonie pour attirer l’attention sur certains détails.

**Ne pas créer un site entièrement rouge.**

# 13. RESPONSIVE DESIGN

Le site doit être parfaitement responsive sur :

* ordinateur
* tablette
* smartphone

Tester particulièrement :

* 320px
* 375px
* 414px
* 768px
* 1024px
* 1440px

Sur mobile :

* menu hamburger
* une seule colonne
* boutons adaptés à la largeur
* textes lisibles
* images correctement dimensionnées
* aucune barre de défilement horizontale.

---

# 14. ANIMATIONS

Ajouter des animations très discrètes :

* apparition progressive des sections
* léger déplacement vertical
* hover des cartes
* hover des boutons
* transitions douces
* soulignement des liens

Ne pas utiliser d'animations excessives.

Respecter :

`prefers-reduced-motion`

pour les utilisateurs qui préfèrent réduire les animations.
